# Stage 3 / Stage 6 — training deps for Unsloth + QLoRA on RTX 50-series.
#
# Install ORDER matters. On RTX 5060 Ti (Blackwell, sm_120), A100 (Hopper),
# and Ampere/Ada cards alike, use a CUDA 13.0 build of torch >= 2.9
# (older cu124 wheels lack sm_120 kernels; cu128 still works but cu130 is
# the current toolkit with the latest fused kernels).
#
#   pip install --upgrade pip
#   pip install torch==2.11.0 torchvision==0.26.0 torchaudio==2.11.0 \
#       --index-url https://download.pytorch.org/whl/cu130
#   pip install -r requirements-train.txt
#
# (We pin to 2.11 not 2.12 because torchaudio 2.12 isn't published on cu130
# yet — torch+torchvision 2.12 are, so you can move the trio there once
# torchaudio catches up. The cu130 kernel features for Blackwell sm_120
# and A100 sm_80 are already present in 2.11.)
#
# IMPORTANT: this file deliberately does NOT pin torch/torchvision/torchaudio
# so it cannot downgrade the cu130 wheels you installed above. The version
# constraints below are picked to be compatible with torch 2.9+ — bumping
# xformers floor to 0.0.29 avoids the 0.0.28 wheel (which forces torch==2.5).
#
# Unsloth pulls additional wheels at runtime. If install breaks, follow
# https://github.com/unslothai/unsloth#installation-instructions for
# the exact pip line that matches your torch+cuda combo.
